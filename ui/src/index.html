Strong — flagship reasoning models (GPT-6 Astra, Claude Fable 5.1, Gemini 3.1 Pro). Best answers on hard exam questions. Slow (30 s – 10 min per answer for deep reasoning) and expensive (up to $50 per 1M output tokens). Use for the hardest MCQs or when Medium keeps missing.

Cheap — fast + affordable (GPT-5.6 Luna, Claude Haiku 4.5, Gemini 3.5 Flash-Lite). ~2 s answers, cheap enough for study drills. Good for factual recall, weaker on multi-step math/logic.

AutoSolver & Agent Point-and-solve, hands-free

How it works: land on a question, then hold Left-Click for ~2s (anywhere). The overlay snapshots the screen, solves it, and shows the answer in a tiny capture-proof dot. Turn on Auto-click below and it also moves the mouse and clicks/type the answer in for you (humanized). It never presses Next / Submit.
Works with this window closed — only the injected overlay needs to be running.

Auto-click the answer Ctrl+Shift+Alt+J
ON: the mouse moves and clicks / types the answer in automatically (humanized motion). OFF (default): display-only — the answer is shown in the dot, nothing is clicked. Safer / more discreet.
Humanized motion
Curved, variable-speed mouse glide + natural click dwell + human typing rhythm instead of instant teleport-clicks. Recommended.

Typing speed
Words per minute. 60-90 = slow & safe (long essays), 110-160 = comfortable average, 200+ = fast typist. Default 110.

Humanize (typos, hand model, tempo)
Full Dhakal CHI'18 engine: log-normal timing, 8-finger bigram model, tempo momentum, occasional typos with backspace-and-retype, sentence-end pauses. Turn OFF for constant-rate typing with no typos (useful for scripted paste-like automation).
Paste mode (fast, no humanization)
Instead of typing character-by-character, copy the text to the clipboard and fire Ctrl+V. Instantaneous, but hostile targets that behavioral-analyze input (typing rhythm) will see a clipboard event instead of typing. Off by default.
Planning pause before typing starts
A short 200-850 ms delay before the first keystroke (writers stage a sentence in their head before typing). Turn off for instant typing.
Wait for modifier keys to release
Before typing, poll Ctrl/Shift/Alt until they're physically up. Prevents your first character from combining with a still-held hotkey modifier (e.g. Ctrl+Alt+T's Ctrl leaking into the first typed key). Recommended ON.
